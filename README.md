## Proyectos

### Medidor de pulso cardiaco

Construcción de un medidor de pulso cardiaco utilizando sensores
infrarrojos, amplificadores y un ESP32 Mini.

El proyecto incluyó la adquisición de la señal, el procesamiento de los
datos y el envío de información mediante comunicación MQTT utilizando
Mosquitto.

### Sistema automático de llenado de botellas

Diseño y construcción de un sistema automático de llenado para botellas,
utilizando un PLC Siemens S7-1200 como controlador principal.

El sistema integra válvulas, una celda de carga y un sistema de control
auxiliar basado en Arduino para automatizar el proceso de llenado.
